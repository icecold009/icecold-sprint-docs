# Demo script

Target length: **2:30–3:00**

## 0:00–0:25 — Problem

“When an exam is close, students do not need another generic chatbot. They need to know what to study next, how long to spend, and whether they actually improved.”

## 0:25–0:55 — Setup

Select Biology Exam Sprint, show the topics, confidence levels, and available study time.

## 0:55–1:30 — Plan

Generate the sprint. Show the prioritized topics, time blocks, and reason for the first recommendation.

## 1:30–2:15 — Quiz

Open the first topic, answer five questions, submit the quiz, and show the score with an explanation.

## 2:15–2:40 — Adaptation

Show that the next recommendation changes based on the score. Demonstrate progress updating.

## 2:40–3:00 — Technology and close

Explain that native.builder created and deployed the application, deterministic logic keeps the schedule reliable, and Fireworks provides quiz generation with a fallback for reliability.

Do not claim features that are not visible in the final public app.
